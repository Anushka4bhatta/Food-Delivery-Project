# 🍔 Food Delivery Demand Analytics Using PySpark & Power BI

### Big Data Analytics Project | Food Delivery Domain | Group-by Analytics

<p align="center">
  <b>Analyzing 50,000 Food Delivery Orders using Apache Spark, PySpark and Power BI</b>
</p>

---

## 📌 Project Overview

Food delivery platforms generate large amounts of transactional data containing information such as order time, location, cuisine, number of items and order value.

This project analyzes food-delivery order data using **Apache Spark and PySpark** to identify:

- Popular cuisines
- Peak ordering hours
- Location-wise demand
- Day-wise ordering patterns
- Revenue by cuisine
- Cuisine preferences across locations

The processed results are visualized using **Microsoft Power BI** through an interactive analytical dashboard.

> **Dataset Note:** The dataset used in this project contains 50,000 synthetic food-delivery orders generated for academic demonstration. It does not represent real customer transactions from any food-delivery company.

---

# 🎯 Problem Statement

Food delivery businesses need to understand customer ordering patterns to improve restaurant availability, delivery operations, resource allocation and demand planning.

The objective of this project is to process food-delivery order data using a Big Data framework and extract meaningful patterns using **group-by analytics and aggregation operations**.

---

# 🚀 Objectives

The main objectives of this project are:

1. Process food-delivery data using Apache Spark.
2. Clean and prepare the dataset for analysis.
3. Perform group-by and aggregation operations using PySpark.
4. Identify the most popular cuisines.
5. Identify peak ordering hours.
6. Analyze location-wise order demand.
7. Analyze day-wise ordering patterns.
8. Calculate revenue and average order value by cuisine.
9. Analyze cuisine demand across different locations.
10. Visualize the analytical results using Power BI.

# 📊 Dataset

The project uses a synthetic dataset containing **50,000 food-delivery orders**.

### Dataset Attributes

| Column | Description |
|---|---|
| `order_id` | Unique order identifier |
| `order_time` | Date and time of the order |
| `location` | Customer/order location |
| `cuisine` | Type of cuisine ordered |
| `total_items` | Number of items in the order |
| `order_value` | Total value of the order |
